1、纯净版immortalwrt,不含任何插件

2、可以使用相应内核版本的immortalwrt官方软件源

3、支持安装第三方插件，如lucky,easytier, openclash等

使用双USB公头线刷机: 双公头的USB线连接电脑和玩客云，使用USB_Burning_Tool刷机。<br>
